# Personal Site

A small, static personal website. The page is in `index.html`; edit the name, introduction, project descriptions, and email address to make it yours.

## Publish with GitHub Pages

1. Push `index.html` to the `eun0115/eun0115` repository on GitHub.
2. Open the repository's **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the branch containing `index.html` and the `/(root)` folder, then save.
5. After GitHub finishes deploying, visit <https://eun0115.github.io/eun0115/>.

The image and web fonts are loaded from external services, so they need an internet connection to appear.
